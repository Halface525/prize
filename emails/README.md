# 邮件模板

委员会对外发送的五封信。

| 文件 | 用途 | 主题行 |
| --- | --- | --- |
| `01-application-received.html` | 收到申请后回执 | 【半面奖】申请已收到 |
| `02-award-notification.html` | 评选结束后通知获奖者 | 【半面奖】获奖通知 · 第 ＿ 期 |
| `03-committee-appointment.html` | 委员会有人加入 | 【半面奖】委员会聘书 |
| `04-publication-notice.html` | 网站公示后告知获奖者 | 【半面奖】公示完成 · 第 ＿ 期 |
| `05-charter-amendment.html` | 章程修订后 | 【半面奖】章程修订通知 |

打开 `index.html` 可以一次看全部（含主题行与使用时机）。

## 怎么发

1. 浏览器打开某一封 → **全选（Ctrl+A）→ 复制 → 粘进邮件正文**。Gmail 会保留格式。
2. **替换所有 `{{...}}` 占位符**（见下）。
3. 主题行从 `index.html` 上复制，别用默认的「无主题」。
4. **发之前先发一封给自己**，在手机上看一遍。很多邮件问题只在窄屏上才显形。

## 占位符

模板里**没有任何写死的具体内容**——奖项名、金额、日期、获奖理由全是占位符。

形式是 `{{大写英文}}`，不是下划线。理由：

- **下划线看不出区别**。十个 `＿＿＿` 长得一样，没法逐个跳。
- **`{{AMOUNT}}` 不可能被误发**。一长串看起来正常的文字里混一个该改没改的数字，
  很容易就这么发出去了；而 `{{AMOUNT}}` 你自己读一遍都会立刻发现。
- **能在 Gmail 里 Ctrl+F 搜 `{{` 逐项替换**。

完整对照表见 `index.html`。几条容易搞错的：

- **页脚的站点地址是写死的**，不是占位符：`https://halface525.github.io/prize/`，
  藏在 `href` 里，正文只显示「访问官网」。
  日后若换自定义域名，五个文件都要改（搜 `halface525`）。
- **`{{DATE}}` 是「本信日期」，不是事件日期。** 收到申请、开奖、公示各有自己的日期
  （`{{RECEIVED_DATE}}` / `{{DRAW_DATE}}`），可能与本信日期不同，所以分开命名。
- **`{{AMOUNT}}` 只填数字**，`¥` 已经写在模板里了。
- **`{{DOMAIN_NUM}}` 填罗马数字**（IV），站点「奖项」页每个领域标题上都有。
- **`{{REASON}}` 不要另写一份**。委员会为网站公示写的那段「获奖理由」就是它。
  两处措辞不一致时以网站为准（章程第三十三条：开奖记录一经公示不予修改），
  所以直接复制网站那段。

**替换完最后搜一次 `{{`，确认一个不剩。** 这一步比前面每一步都重要。

## 为什么这么写（别改坏了）

HTML 邮件和网页是两种东西。下面每一条都是踩过坑的：

- **用 table 排版，不用 `display:flex`** —— **Outlook 用 Word 的渲染引擎，不认 flex**。
  细节行（`.details`）本来很容易写成 flex，那样在 Outlook 里标签和值会挤成一行。
- **不依赖图片** —— 图片默认被屏蔽，所以半面标记是两格 table 拼的，不是图
- **宽度 560px 上限** —— 邮件客户端的通行惯例
- **每封都有一段隐藏的「预header」** —— 就是收件箱列表里那行摘要。改它能改列表里显示什么
- **深色块用藏青 `#1b2a6b`**，与站点页脚同色；金色 `#c9a961` 做点缀
- **正文里不出现裸网址**，页脚链接文字写「访问官网」，地址只放在 `href` 里。
  `halface525.github.io/prize` 一亮出来，「这是个 GitHub Pages 个人站」就穿帮了，
  跟整套「正式机构」的调子冲突。同理，**日后也别在邮件正文里贴站点地址**。
  链接文字用**动作**（「访问官网」）而不是**名词**（「本奖网站」）——单独占一行时，
  名词会被读成小标题，动作才明确是链接。而「官网」那点没来由的分量，
  正好是全站「端着一本正经」的同一个玩笑。
  注意章程正文里仍用「本奖网站」（第三十二条的法定术语），两者不冲突。

### 关于 `<style>` 块

模板用的是 `<head>` 里的 `<style>` 块，**不是逐条内联**。这是有意的取舍：

- 你的发信方式是「浏览器打开 → 复制 → 粘进 Gmail」，而 **Gmail 在粘贴时会把计算后的样式
  转成内联**，所以对这条路径没有影响
- 用 `<style>` 块，文件可读、好改。这个站你会反复改文案，纯内联样式表改起来很痛苦
- **若日后改用 ESP / API 群发，必须先把样式内联。** 那种路径下很多客户端会剥掉
  `<style>`，邮件会变成裸 HTML。工具：`juice`、`premailer`，或大多数 ESP 自带的
  「CSS 内联」选项

### 半面标记

站点 logo 是**左金右藏青的半圆**。邮件里画不出圆——不能用 SVG，图片又默认被屏蔽——
所以用两格 table 拼：

```html
<table role="presentation" class="mark" cellpadding="0" cellspacing="0" border="0" align="center">
  <tr><td class="m-left">&nbsp;</td><td class="m-right">&nbsp;</td></tr>
</table>
```

```css
.mark td { width: 26px; height: 52px; font-size: 0; line-height: 0; }
.mark .m-left  { background: #c9a961; border-radius: 26px 0 0 26px; }  /* 金，左半 */
.mark .m-right { background: #1b2a6b; border-radius: 0 26px 26px 0; }  /* 藏青，右半 */
```

`border-radius` 在 Outlook 里不生效，那里会退化成**两色方块**——不难看，可以接受。
`font-size:0; line-height:0` 是防止 `&nbsp;` 把格子撑高。

### 字体的降级

站点用的是 Playfair Display + Noto Serif SC，**邮件里加载不出来**，所以退到系统字体：

| 站点用的 | 邮件里退到 |
| --- | --- |
| Playfair Display | `Source Serif Pro`（同为高对比度衬线，@import 加载）→ `Georgia` |
| Noto Serif SC | `Noto Serif SC`（@import 加载）→ `"Songti SC"` → `"SimSun"`（中易宋体） |
| Inter | `-apple-system, "Helvetica Neue", Arial, sans-serif` |

`@import` 保留着，因为**它在浏览器预览时有效**（你复制粘贴之前看到的就是它）。
真发出去被剥掉了也不亏——`Georgia` 兜底，且各平台都有 Georgia。

**中文字体的兜底要显式写**：`Source Serif Pro` 没有汉字，`Georgia` 也没有，
不写 `"Songti SC", "SimSun"` 的话浏览器的中文字形会随机落到某个默认字体上。

### 深色模式

每封都设了 `<meta name="color-scheme" content="light">`，但**部分客户端仍会强制反色**。若发现反色后难看，那是客户端行为，不是模板的问题。邮件没有可靠的深色模式方案，能做的只有显式声明浅色。

## 一件必须注意的事：钱

获奖通知承诺付款，但**回执和通知里都写着「委员会从不在任何环节索要银行账户信息」**。这两件事必须同时成立，否则：

1. 自相矛盾——一边说从不要账户信息，一边发邮件要账户信息
2. 更糟的是，**你在训练获奖者「收到要银行账户的邮件就给」**，而这正是诈骗的标准套路

**规则：邮件里永远不要主动索要账户、卡号、验证码、身份证。**

现在的模板写的是「领取方式由委员会另行告知」——留了口子。具体执行时，让**获奖者先提出方式**（比如他说「转我微信」），委员会再照办。这样主动性在对方手里，不是你在索取。

另外两点：

- **偶然所得税**：中国税法下奖金属「偶然所得」，名义税率 20%。金额小到没人会管，但心里有数。不要在邮件里写税务建议。
- **未成年人**：现在的奖项面向大学生（成年人），不涉及。若日后要颁给中学生，付款和公示都得先经监护人。

## 维护

- 这五个文件**不参与网站构建**——`emails/` 在 `public/` 之外，不会被部署上去
- 若要连同网站一起公开（这本身也是一种公示），把整个目录移到 `public/emails/` 即可
- 改了章程条文号，记得同步这几个模板里引用条文的句子（搜 `章程第`）
